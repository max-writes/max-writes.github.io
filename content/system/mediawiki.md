## Creating pages
1. Start with a topic
- I get these from life (anything I'm curious about) or books I'm reading & keep an informal list of stuff I could explore
- If I'm bored, I use the list to make a page (there's no direction or prioritization of topics)
- This time, I'm picking one of the topics from a book I read earlier this year - Communities of Practice (CoP). I know about this topic in a general sense but only recently joined one at work, so I'm curious about learning more.


2. Make a list of questions
- what is a community of practice?
- what is the history (corporate or otherwise)?
- what context makes a CoP useful?
- what types of topics do CoPs discuss?
- is there a standard/recommended agenda, cadence, or flow for CoPs?

3. Internet search articles about the topic & answer the questions. Note anything else interesting or new questions.

4. I usually answer the questions as a draft but if I just go down the list of questions, I'll have an additional step to revise the answers into a wiki page draft. This is where I add headings too and outline the page based on what I found.
- My wiki approach is to create pages with basic definitions and then expand on them later, rather than to have all comprehensive information at the front. 
- As a personal wiki, I'm trying to use it to document stuff for myself to reference later as well as a way to see where connections grow between topics of interest. 

5. Create the page given my page template and add all the code and such.

a. Search for the page by title (using sentence case) or click a red link in the wiki
b. Since it doesn't exist yet, you'll get the option to create it - follow that instruction
c. Start with the general template which I have saved in a .txt file on my computer.
d. Select "Show preview" to read and make any changes as needed. The category doesn't show up until publishing.
e. First comment: Created page and populated with topic details

6. When you're ready to publish, push "Save page"
7. Select Actions > Protect > Select "Allow only administrators" and "Protect pages included in this page" then "Confirm"
8. Any links to this page will turn blue, or you can now add links to this page if needed

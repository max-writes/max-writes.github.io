## Creating pages
--- create a new md page
content/field-notes: random tiny thoughts/ideas connected to things you've read/learned or this digital garden
content/thoughts: basically the folder of all the things that you're thinking about (topic based)
content/outlines: formal outlines for articles or ideas not quite formed
content/slightly-polished: ideas that have been formed and edited (some are updated with review, others not - if not updated with reviews, it should be stamped with date and context)
content/system: 

1. open a page in the folder where you're creating the page (probably thoughts)
2. copy the header stuff
3. select new file icon above the file list
4. paste the header, update title, tags, and date (date of page creation)
5. go back to the other page and copy the footer stuff (modification history) and drop it in the new page under a <!-- --> comment so it's there if/when you modify this page.
6. add/type content below the header.
7. add to all.md

**modification history**
* bottom of each page: date & changes made 
* all.md: dd all changes to site (new styles, new pages, overall updates)
